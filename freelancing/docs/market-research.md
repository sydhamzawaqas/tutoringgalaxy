# Market research (October 2026)

## Demand signals

First-party Fiverr data (search-interest growth unless noted):

| Niche | Signal | Claude Code fit |
|---|---|---|
| Claude Code specialist (apps, agents, automation) | +938% in 6 months, fastest-growing AI service | ★★★★★ |
| AI development | Orders +118% YoY (Fiverr Q1 2026 earnings call) | ★★★★★ |
| n8n / AI workflow automation | +125% | ★★★★ |
| AI mobile app development | +92% | ★★★★ |
| Vibe coding (incl. fixing vibe-coded apps) | +61% | ★★★★★ |
| AI voice agents | +49% | ★★★ |
| AI website development | +39% | ★★★★★ |
| Excel data cleaning / PDF→Excel | +210% / +153% | ★★★★ (small, fast, good for reviews) |

**Avoid / low margin:** generic WordPress bug fixes, basic brochure sites,
plain content writing — crowded and undercut by AI.

Caveat: these are Fiverr numbers; Freelancer.com demand follows the same trend
but check live project counts per skill during the audit.

## Target niches (priority order)

1. **Custom AI agents & automations built with Claude Code** — highest growth,
   high ticket.
2. **Fix / finish vibe-coded apps** (Lovable, Bolt, Cursor, v0, Replit) —
   desperate buyers, little specialised competition.
3. **Next.js + Supabase web apps / SaaS MVPs** — core full-stack skill;
   `tutoringgalaxy` is the portfolio piece.
4. **Quick automations** (scripts, scraping, Excel/PDF, n8n) — fast wins to
   build fresh reviews.

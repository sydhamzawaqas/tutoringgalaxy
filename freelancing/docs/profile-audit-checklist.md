# Profile audit checklist

Score each item 0–2 (0 = missing/bad, 1 = OK, 2 = strong). Fix the 0s first.

## Profile

| Item | What "strong" looks like |
|---|---|
| Photo | Clear, friendly, professional face photo |
| Headline | Specific outcomes, not a job title. e.g. *"AI Agents · Next.js SaaS · Automations · Fast, tested delivery"* |
| Summary — first 2 lines | What the client gets (visible in previews). No "Hi, I am…" |
| Summary — body | Proof (results, numbers), services list, stack, process, call to action |
| Skills | Current and matching target niches: Claude Code, AI Agents, LLM integration, Next.js, React, TypeScript, Node.js, Supabase, PostgreSQL, n8n, Automation, Web Scraping, Python. Remove outdated/irrelevant ones (project matching runs on skills) |
| Portfolio | 4–6 recent items with screenshot + 2-line result. Include tutoringgalaxy and 2 AI-agent demos |
| Hourly rate | Within the range in `pricing.md`, not the cheapest in the niche |
| Verifications | ID, payment, phone, email all done |
| Exams / certifications | Relevant ones passed (they show as badges) |
| Reviews | Recent (last 90 days). If old → win small quick projects to refresh |
| Availability / response time | Online during client hours; reply within 1 hour |

## Activity

| Item | Check |
|---|---|
| Bid volume | Are you using all available bids? What's the membership bid limit? |
| Bid speed | Are bids placed within ~30 min of posting? |
| Bid quality | Personalised, mentions the project specifics, has a mini plan |
| Bid price | Too low (looks cheap) or too high vs. other bids? |
| Win rate | Bids → replies → awards. Below ~5% award rate = fix bids/profile |
| Earnings trend | When did it drop? What changed (skills, rate, inactivity)? |

## Output of an audit

1. Score table + top 5 problems ranked by impact.
2. Ready-to-paste copy: headline, summary, skills list, rate.
3. Portfolio plan (what to add, what to remove).
4. 2-week action plan.

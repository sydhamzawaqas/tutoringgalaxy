# Bid & client playbook

## Bid structure (keep it under ~150 words)

1. **Hook (1 line):** restate their exact problem in their words.
2. **Proof (1–2 lines):** a similar thing you built + link.
3. **Mini plan (3 bullets):** how you'll do it, concrete tech.
4. **Timeline + price:** milestones.
5. **One smart question** that shows you read the brief.

Speed matters: bid within ~30 minutes of posting when possible.

## Template — AI agent / automation

> Hi {name}, you need {their goal in one line} — I build exactly this kind of
> {AI agent/automation}.
>
> Recently built: {similar project} ({link}).
>
> Plan:
> • {step 1 — e.g. connect to your {tool} via its API}
> • {step 2 — agent logic with {LLM}, guardrails, logging}
> • {step 3 — deploy + short handover video}
>
> Delivery: {X} days, {price} in {n} milestones.
> Quick question: {specific question about their data/tools}?

## Template — fix a vibe-coded app

> Hi {name}, I specialise in taking {Lovable/Bolt/Cursor} apps that are stuck
> and getting them working and production-ready.
>
> First I'll audit the code and give you a clear list of what's broken, then fix:
> • {the bug they mentioned}
> • {likely related issue: auth/db/deploy}
> • tests + deploy so it stays fixed
>
> Milestone 1 (audit + {main bug}): {price}, {X} days. Can you share the repo
> or a screen recording of the error?

## Template — Next.js web app / website

> Hi {name}, I'll build your {site/app} with Next.js + {Supabase/DB}: fast,
> SEO-ready and easy for you to edit.
>
> Example: {portfolio link}.
>
> Plan: {pages/features} → {integrations} → deploy on {Vercel/your host}.
> {X} days, {price}. Do you already have designs or should I propose one?

## Client message templates

**Clarify scope:** "Thanks! Before I start, can you confirm: {1}, {2}, {3}? Then
I'll send a fixed quote with milestones."

**Scope creep:** "Happy to add {feature}. It's outside the original scope, so I'll
add it as a new milestone: {price}, {X} days. Shall I create it?"

**Delivery:** "Done ✅ — {what was delivered}. Here's how to test it: {steps}.
Includes 2 revision rounds; let me know any changes."

**Review ask:** "Glad it's working well! If you have a minute, a review would
really help me. Thanks for the great project."

## Never

- Send messages or bids automatically (bot activity = ban risk).
- Ask to move payment or chat off-platform.
- Promise a deadline you haven't checked against current workload.
